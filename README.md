## Project Overview

This repository documents a Cell and Molecular Biology laboratory investigation of the molecular relationship between DNA mutation, protein sequence change, cellular function, and disease phenotype using the LRRK2 G2019S mutation associated with familial Parkinson disease.

The project includes the wild-type LRRK2 coding sequence and predicted protein, the documented G2019S mutant, a student-created artificial mutation, protein-sequence comparisons, molecular interpretation, and the final laboratory report.
